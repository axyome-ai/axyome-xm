# Tutorials

Step-by-step guides that end with something working. There are two tracks, Business and Coder, each in three levels. Each tutorial says what to do before it.

| Track | Level | Tutorial | Time | You will |
| --- | --- | --- | --- | --- |
| Business | Beginner | [Vibe coding with Copilot and Axyome XM](vibe-coding-with-copilot.md) | 30 min | Build a one-page sales dashboard by chatting with Copilot, then ask Copilot what you did and save your rules so the next chat remembers them |
| Business | Intermediate | [A small tool built over a week](tool-over-a-week.md) | 3 × 30 min | Build a request tracker over three sessions, pick up each time from memory, recover from a bad change and start a playbook |
| Business | Advanced | [Hand your prototype to developers](handover-to-developers.md) | 45 min | Turn the request tracker and its history into a handover pack developers can act on |
| Coder | Junior | [Debug with memory](debug-with-memory.md) | 30 min | Put the request tracker under git, fix a bug, then fix a similar one from your own history |
| Coder | Intermediate | [A feature across three days](feature-across-three-days.md) | 3 × 30 min | Add a tested CSV export over three sessions, with project rules saved in memory and a pull request summary from memory |
| Coder | Senior | [One memory for Copilot and Claude Code](one-memory-for-copilot-and-claude-code.md) | 45 min | Connect Claude Code to the same memory, refactor with it, and have Copilot find the design decision it saved |

Each track builds on the one before it: the coder track starts on the request tracker the business track hands over.
New to Axyome XM? Start with the [onboarding guide](../onboarding.md).
