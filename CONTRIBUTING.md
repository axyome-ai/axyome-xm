# Contributing to Axyome XM

Thank you for your interest in Axyome XM!

Axyome XM is developed in a private repository. This public repo is the companion documentation hub and community issue tracker.

---

## How to Contribute

### Report a Bug

-> [Open a bug report](https://github.com/BI-Expertise/axyome-xm/issues/new?template=bug_report.yml)

**Before filing:**
- Search [existing issues](https://github.com/BI-Expertise/axyome-xm/issues) for duplicates
- Try `Ctrl+Shift+P` -> **Axyome XM: Show Statistics** to confirm the extension is running
- Include your platform (Windows/Linux/macOS), VS Code version, and extension version

### Request a Feature

-> [Open a feature request](https://github.com/BI-Expertise/axyome-xm/issues/new?template=feature_request.yml)

Describe the use case and pain point clearly. The more concrete the scenario, the more actionable the request.

### Ask a Question

-> [Open a question](https://github.com/BI-Expertise/axyome-xm/issues/new?template=question.yml)

### Improve Documentation

Documentation PRs are welcome! All docs live in the `docs/` folder.

1. Fork this repository
2. Edit the relevant file in `docs/`
3. Open a Pull Request against `main`

Good documentation contributions:
- Fix typos or unclear wording
- Add missing examples or screenshots
- Clarify MCP tool parameters
- Add new FAQ entries based on common issues

---

## Code Contributions

Extension source code lives in a private repository. If you want to contribute a feature or fix:

1. Open a [feature request issue](https://github.com/BI-Expertise/axyome-xm/issues/new?template=feature_request.yml) first to discuss scope
2. Wait for maintainer acknowledgment before investing implementation time
3. Implementation details will be coordinated via the issue thread

---

## Issue Guidelines

- One issue per bug/request
- Include reproduction steps for bugs (minimal and complete)
- For MCP tool issues: include the exact prompt, tool call, and response
- For performance issues: include approximate event count from **Axyome XM: Show Statistics**

---

## Code of Conduct

Be respectful. Constructive criticism is welcome; personal attacks are not.
